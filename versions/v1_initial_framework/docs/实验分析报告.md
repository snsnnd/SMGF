# SMGF 实验分析报告

## 1. 实验目的

本文实验围绕状态调制引导场（SMGF）的核心机制展开，目标不是证明方法在任意复杂环境下全局最优，而是验证以下四点：

1. 预测导航项是否能够改善移动目标拦截与前导包围能力。
2. 非保守切向绕障项是否能够缓解传统 APF 在障碍物前方的停滞问题。
3. 构型序参量 `tilde(Psi)` 是否能够改善多智能体从目标同侧出发时的展开与周向覆盖。
4. 环境压力参量 `Omega` 是否能够在窄通道和障碍密集区域自动降低拓扑刚度，实现柔性通过。

SMGF 的核心创新不是单个新力项，而是对拓扑协同项进行双状态连续调制：

`rho_i = eta(Omega_i) * D(tilde(Psi)_i)`

其中：

1. `D(tilde(Psi)_i)` 用于表征群体构型是否仍然偏向目标同一侧。
2. `eta(Omega_i)` 用于表征局部障碍压力是否足以要求群体软化结构。
3. 调制对象是 `F_topo`，而不是最低安全防撞项 `F_safe`。

## 2. 当前实现的实验系统

当前代码已经完成以下模块：

1. 预测导航项 `F_nav`
2. 有界障碍斥力与切向绕障项 `F_hyb`
3. 智能体间安全防撞项 `F_safe`
4. 可调制拓扑协同项 `F_topo`
5. 围捕参考项 `F_enc`
6. 构型序参量 `hat(Psi)_i`、`tilde(Psi)_i` 与构型调制函数 `D(tilde(Psi)_i)`
7. 环境压力输入 `phi_i`、压力状态 `Omega_i` 与压力调制函数 `eta(Omega_i)`
8. 状态调制因子 `rho_i`
9. 指标统计、轨迹绘图和状态曲线绘图

当前已实现的主要场景包括：

1. `S1` 单智能体绕障验证
2. `S2` 多智能体同侧展开实验
3. `S3` 静态目标围捕实验
4. `S4` 窄通道柔性通过实验
5. `S5` 障碍密集环境下移动目标追踪
6. `S6` 高速目标拦截与预测导航实验

## 3. 本轮实验设置说明

本轮实验主要用于验证代码框架、实验流水线和指标系统是否闭环可用，因此采用了小样本快速统计：

1. 使用 `uv` 进行环境管理与运行。
2. 通过 `uv run smgf run-suite --trials 3 --output outputs/quick_suite` 运行快速基准套件。
3. 结果汇总文件保存在 `outputs/quick_suite/summary_metrics.csv`。

需要强调的是，本轮结果属于“系统搭建完成后的首轮验证结果”，其主要作用是：

1. 检查各模块是否可以稳定联动运行。
2. 检查指标是否能输出并区分不同方法。
3. 暴露参数未充分整定时的失败模式。

因此，本轮结果不应直接视为最终论文结果，而应视为参数整定前的基础实验版本。

## 4. 主要结果分析

### 4.1 场景 S1：单智能体局部绕障

对比方法为 `M1 Traditional APF` 和 `M3 APF-Curl`。

当前结果显示：

1. 两种方法在该简单单障碍场景下都能成功到达目标，成功率均为 `1.0`。
2. `M1` 平均完成时间约为 `12.75 s`，`M3` 平均完成时间约为 `16.48 s`。
3. `M3` 的最小障碍距离约为 `1.24`，明显高于 `M1` 的 `0.63`。
4. `M3` 的输入接近上限比例为 `0`，而 `M1` 约为 `0.317`。

分析：

1. 该场景目前还不足以把传统 APF 的局部极小问题完全激发出来，因此两者都能成功。
2. 切向绕障项带来的直接收益首先表现为更大的障碍安全裕度，而不是更短的完成时间。
3. `M3` 的控制平滑性指标数值偏大，说明当前切向项参数仍偏激进，后续需要继续调低 `lambda` 或加入更强滞回/滤波。

结论：

本轮结果已经证明混合绕障模块可运行且能改变绕障行为，但要更有说服力地证明“减少局部停滞”，还需要进一步设计更强共线或双障碍夹逼场景。

### 4.2 场景 S2：同侧展开与角度覆盖

该场景用于验证构型调制是否能改善多智能体从目标同侧出发时的展开能力。

当前结果显示：

1. `M4` 与 `M5` 成功率达到 `1.0`，平均完成时间约 `7.42 s`。
2. `M6` 与 `M7` 成功率为 `0`，但最终 `G_max` 已下降至约 `60 deg`，说明角度覆盖本身并不差。
3. `M7` 的平均邻居最小距离与 `M6` 几乎一致，说明此场景下 `Omega` 确实没有发挥主导作用。

分析：

1. 当前 `S2` 的成功失败更多受“围捕半径阈值”和“成功判定窗口”影响，而不是单纯由角度展开质量决定。
2. 从最终 `G_max` 约 `60 deg` 看，群体事实上已经形成较好的周向分布；失败主要说明围捕参考半径与成功判定参数仍需细调。
3. `M4/M5` 与 `M6/M7` 结果接近，说明当前这组参数尚未把 `Psi` 调制的边际收益放大出来。

结论：

当前场景已证明展开与围捕闭环可运行，但尚未充分拉开 `Psi` 消融对比。后续需要通过以下方式增强可解释性：

1. 提高同侧初始偏置程度。
2. 降低固定拓扑方法的“天然好运气”。
3. 单独绘制 `tilde(Psi)` 曲线，比较其下降速度与 `G_max` 收敛速度。

### 4.3 场景 S3：静态围捕收缩

该场景主要验证在群体完成展开后，调制机制能否降低拓扑刚度并促使群体向期望围捕半径收缩。

当前结果显示：

1. `M6` 和 `M7` 成功率为 `1.0`，平均完成时间约 `3.37 s`。
2. `M4` 和 `M5` 成功率约 `0.667`，平均完成时间 `18.9 s`，方差很大。
3. `M7` 的控制代价与控制平滑性均优于 `M4/M5`。
4. `M7` 的最小智能体间距离约 `0.713`，保持在安全距离以上。

分析：

1. 该结果说明“降低拓扑刚度后更容易收缩到围捕半径”的趋势已经出现。
2. 固定拓扑方法在该场景中更容易出现收缩不足或长时间保持刚性结构的问题。
3. `M6` 与 `M7` 表现一致，说明该场景主要验证的是构型演化后的收缩过程，环境压力调制不是关键因素。

结论：

`S3` 是目前最接近论文预期的场景之一，已经初步支持如下论点：

1. 固定拓扑不利于后期围捕收缩。
2. 调制后的拓扑刚度更有利于形成目标附近的收缩围捕结构。

### 4.4 场景 S4：窄通道柔性通过

该场景是验证 `Omega` 压力调制最关键的场景。

当前结果显示：

1. 所有方法都出现不同程度碰撞，说明该场景当前参数仍偏难。
2. `M4` 成功率约 `0.667`，碰撞率约 `0.333`。
3. `M5/M6/M7` 当前仍全部失败，碰撞率较高。
4. `M7` 的 `G_max` 与半径方差较低，说明群体在目标附近的几何分布不差，但通过过程中的安全性不足。
5. `M7` 存在明显的停滞步数，说明压力调制确实在改变行为模式，但当前还没有把它转化为稳定安全通过。

分析：

1. 本轮结果最重要的价值在于暴露出：窄通道问题对参数耦合非常敏感。
2. 当前 `eta_min`、`sigma_Omega`、`d_agent_safe`、`r0`、`k_t` 等参数组合还没有达到“既软化拓扑又保持安全”的平衡点。
3. 当前通道几何与初始编队密度仍然偏紧，容易在入口处发生内部挤压。
4. 如果仅从最终几何指标看，可能会误以为方法有效；但加入碰撞率后可明确看出，当前版本尚不能宣称窄通道性能已达标。

结论：

`S4` 目前还不能作为论文的正结果图，需要继续调参和做通道宽度扫描。它更适合作为当前开发阶段的关键待优化场景。

### 4.5 场景 S5：障碍密集环境下移动目标追踪

该场景是完整复杂环境综合能力测试。

当前结果显示：

1. 所有方法成功率均为 `0`。
2. 所有方法碰撞率均为 `1.0`。
3. `M7` 的角间隙和半径方差相对固定拓扑有所改善，但仍无法支撑任务成功。
4. `M1/M3` 虽然在控制输入上更简单，但在该密集障碍场景中无法形成稳定围捕结构。

分析：

1. 该结果符合预期中的“系统尚未完成最终整定”的状态。
2. 当前问题不在于代码不能运行，而在于复杂场景中参数组合、目标轨迹、障碍密度和初始位置仍未达到稳定任务区间。
3. 这一场景同时耦合了预测导航、混合绕障、拓扑协同、围捕参考和安全项，是最适合最后阶段做系统整定和消融统计的场景。

结论：

当前 `S5` 更适合作为后续主调参场景，而不是当前版本的论文展示主图。

### 4.6 场景 S6：高速目标与预测导航

该场景用于验证预测导航项的作用。

当前结果显示：

1. 所有方法成功率仍为 `0`，碰撞率为 `1.0`。
2. 在单次对比中，`T_p = 1.0` 相比 `T_p = 0.0`，最终 `G_max` 与平均半径略有改善，但预测中心误差变大。
3. 输入接近上限比例较高，说明高速目标场景下系统正在频繁逼近控制上限。

分析：

1. 这表明预测导航的物理作用已经被激活，但当前预测时间、围捕半径与初始站位还没有形成有效拦截构型。
2. 过大的预测时间可能导致过度超前，带来更强振荡和追踪误差。
3. 这一场景后续应按实验设计文档，对 `T_p = 0, 0.5, 1.0, 1.5` 做系统扫描，而不是只看单次点值。

结论：

当前 `S6` 已具备做预测导航扫描实验的代码基础，但还未进入论文可直接引用的成熟结果阶段。

## 5. 当前阶段的总体结论

结合本轮快速套件结果，可以得出以下阶段性结论：

1. **代码层面**：SMGF 主方法、对比方法、指标系统和批量实验流水线已经全部跑通。
2. **模块层面**：`Curl`、`Psi`、`Omega` 和围捕参考项都已在系统中实际生效，而不是停留在公式层面。
3. **结果层面**：`S3` 已经出现较符合论文预期的正向结果；`S1` 也体现出更大的安全裕度。
4. **问题层面**：`S4/S5/S6` 的复杂场景仍需进一步整定，否则无法支撑最终论文主结论。

因此，当前工作状态可以概括为：

> 实验系统已经从“理论公式与实验设计”推进到“可运行、可统计、可视化”的阶段，但距离论文最终版仍需完成参数整定、消融增强与更大样本统计。

## 6. 后续建议

为了把当前代码与结果推进为更完整的论文实验，建议按以下顺序继续：

1. 优先调通 `S4` 窄通道场景，因为这是 `Omega` 调制最核心的证据。
2. 对 `S2` 和 `S3` 单独调整围捕半径、成功判定阈值和初始构型，使 `Psi` 调制贡献更清晰。
3. 对 `S6` 进行 `T_p` 扫描，形成“预测时间 vs 拦截性能”的曲线。
4. 在 `S5` 上逐步增加障碍密度，而不是一次性使用高难度复杂地图。
5. 当默认参数稳定后，再执行 `50-100` 次随机种子统计，生成最终表格和箱线图。
