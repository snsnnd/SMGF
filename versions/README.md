# Versions

`versions/` 用于归档本项目不同阶段的文档与实验结果快照，不替代根目录当前可运行代码。

## 目录说明

1. `v1_initial_framework/`
   初始实现阶段，包含论文原理、实验设计、首轮实验分析和最早一批实验结果。
2. `v2_optimization_diagnostics/`
   优化与诊断阶段，包含失败分解、S4/S6 调参与聚焦优化实验结果。
3. `v3_restructured_experiments/`
   实验体系重构阶段，包含 A-E 分层实验设计与分组烟雾实验结果，以及合并总表。

## 当前代码

根目录中的 `src/`、`tests/`、`pyproject.toml`、`README.md` 仍然代表当前最新可运行版本。
