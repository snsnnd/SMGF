# Docs

本目录用于保存当前版本仍然有效的项目文档，避免根目录堆积过时报告。

## 当前目录结构

1. `phase1/`
   第一阶段主干论文、分层实验、图表与边界分析相关文档。
2. `exploration/`
   面向后续方法分支、控制组合方式和环境理解机制的探索性实验报告。

## 使用建议

1. 项目总定位、方法主线和后续研究树：优先阅读 `../SMGF研究规划文档.md`
2. 第一阶段实验闭环与论文写作：优先阅读 `phase1/README.md`
3. 当前最活跃的 corridor/energy/release 分支：优先阅读 `exploration/M43-M62方法分析与M43_M62交叉验证_20260616.md`
4. 较早期的分支探索总览：阅读 `exploration/SMGF_分支探索实验报告.md`
5. `M43/M62` 历史工作文档：阅读 `exploration/M43统一能量场重构路线整理.md` 与 `exploration/structured_energy_tank_minimal_model.md`
6. 历史版本与旧实验快照：阅读 `../versions/README.md`
