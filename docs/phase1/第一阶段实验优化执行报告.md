## 4. 代表性结果分析

### 4.1 安全项对照：`A3`

从 `A_basic_modules` 的结果看：

1. `M10` 去掉安全项后，最小智能体距离极小，几乎重合；
2. `M7` 保留安全项后，最小智能体距离明显更大；
3. 但两者当前都还会发生智能体间碰撞。

结论：

1. `F_safe` 是必要的；
2. 但当前 `F_safe` 还不足以在复杂交汇场景下单独完成强防撞；
3. 这正符合主干论文中对安全项的谨慎表述。

### 4.2 围捕角度覆盖：`B` 组

从 `B_encirclement_geometry` 的烟雾结果看：

1. `b3_moving_target_open_encirclement` 中，`M4/M7/M9` 都能无碰撞成功；
2. `M9` 的 `gmax_mean` 显著小于 `M4/M7`；
3. `s2_same_side_expansion` 中，`M9` 把 `gmax_mean` 压到约 `60 deg`，但仍会碰撞。

结论：

1. 显式角度正则对角度覆盖是有效的；
2. 原始 `M7` 对角度覆盖的改善仍然偏间接；
3. 角度覆盖与群体安全仍是两个不同问题，需要分别对待。

### 4.3 压力场分级验证：`C` 组

从 `C_pressure_passage` 的结果看：

1. `s4_narrow_passage_easy/medium/hard` 已形成明确分级；
2. 当前很多失败主要由 `agent_collision_rate` 主导；
3. `obs_collision_rate` 反而不是主导项。

结论：

1. 当前 `Omega` 机制的主要瓶颈不是“识别不到通道”；
2. 而是“通道约束下群体内部挤压与通过后重构不稳定”；
3. 这说明后续优先级应放在内部安全与方向性软化，而不只是继续放大 `Omega` 标量衰减。

### 4.4 预测时间扫描：`D1`

从 `outputs/d1_scan_tuning_v1/summary_metrics.csv` 可见：

1. 当前 `M4/M7/M9` 在 `D1` 中仍全部失败；
2. 主要失败模式是 `agent_collision_rate = 1.0`；
3. 随 `T_p` 增大，`completion_time_mean` 有下降趋势；
4. `M9` 的 `gmax_mean` 显著下降，说明角度覆盖改善明显；
5. 但 `radius_error_final_mean` 反而变大，说明过强角度展开和前导追踪之间存在新的权衡。

结论：

1. 当前已经可以初步看到“预测时间增加会改变追踪行为”；
2. 但还不能宣称已经找到最优 `T_p` 区间；
3. 下一步应优先降低目标速度或进一步增强内部安全，先让 `D1` 成功率脱离零值。

## 5. 当前阶段已经得到的最重要结论

本轮优化后，可以更清晰地说：

1. 第一阶段实验结构已经基本搭好；
2. 当前主干论文最重要的实验短板不再是“实验混在一起看不懂”；
3. 现在已经能明确定位：
   `A` 组主要看基础机制，
   `B` 组主要看角度覆盖与围捕几何，
   `C` 组主要看环境压力和群体内部安全冲突，
   `D` 组主要看预测时间影响；
4. 当前最主要未解决问题是：
   带障碍或高速目标条件下的 `agent_collision`。

## 6. 下一步建议

基于当前结果，建议接下来这样推进：

1. `B` 组：继续调 `M9`，明确角度正则的收益边界；
2. `C` 组：优先让 `s4_narrow_passage_easy` 中 `M7` 不差于 `M4`；
3. `C` 组：必要时引入方向性拓扑软化增强版；
4. `D` 组：在降低目标速度或提升安全项后重新做 `T_p` 扫描；
5. 在 tuning split 确定参数后，直接运行 validation split：

```bash
/home/aaa/.local/bin/uv run smgf run-phase1 --split validation --output outputs/phase1_validation_v1
```

6. 最后再运行 final split 形成论文正式统计。
