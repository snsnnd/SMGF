# 第一阶段最小实验闭环清单

## 1. 目标

本清单只服务于一个目标：

> 让 `SMGF-Core` 的第一阶段主干论文具备最小但完整的实验闭环。

这里不追求“所有复杂场景全部成功”，而追求：

1. 关键机制各自有对应实验；
2. 每个主张至少有一组可解释证据；
3. 失败场景有明确归因，不是笼统说“方法无效”；
4. 调参与验证数据分离。

## 2. 必须项清单

### A. 基础模块必须成立

1. `A1` 单智能体无障碍目标到达
   目标：证明导航与限幅本身可运行。
   最低标准：
   - `M1/M2 success_rate = 1.0` 或接近 1.0

2. `A2` 单智能体单障碍绕行
   目标：证明 `Curl` 能改变绕障行为。
   最低标准：
   - `M3` 的 `min_obs_distance` 不低于 `M1/M2`
   - 至少能体现绕障行为差异

3. `A3` 多智能体无障碍防碰撞
   目标：证明 `F_safe` 必要。
   最低标准：
   - `M7` 的 `min_agent_distance` 明显大于 `M10`

### B. 围捕与构型主张必须有证据

1. `B1` 静态目标均匀初始围捕
   目标：验证 `F_enc` 至少能提供半径收敛趋势。

2. `B2` 同侧初始展开
   目标：验证 `Psi` 对角度覆盖的作用边界。
   最低标准：
   - 至少能比较 `M4/M5/M6/M7/M9` 的 `Gmax`、`inside_final`、`agent_collision_rate`

3. `B3` 移动目标无障碍围捕
   目标：验证开阔环境下移动目标围捕闭环可运行。
   最低标准：
   - `M4/M7` 至少有一组正向成功证据

### C. 压力场必须通过分级实验验证

1. `C1` 宽通道
   目标：验证 `M7` 至少不明显差于 `M4`

2. `C2` 中等通道
   目标：明确 `Omega` 的失败或收益来自哪里

3. `C3` 窄通道
   目标：作为极限压力测试，而不是唯一证据来源

最低标准：

1. 必须报告：
   - `obs_collision_rate`
   - `agent_collision_rate`
   - `passage success`
   - `formation recovery / hold behavior`
2. 如果 `M7` 不优于 `M4`，也必须明确失败归因。

### D. 预测导航必须有独立趋势验证

1. `D1` 高速目标无障碍
   目标：证明 `T_p` 改变会系统性改变行为。

2. `D2` 高速目标 + 单障碍
   目标：验证预测与轻度避障的耦合趋势。

最低标准：

1. 至少有 `T_p = 0, 0.3, 0.7, 1.0, 1.3, 1.5` 的扫描结果；
2. 至少能讨论 `completion_time`、`current_center_error`、`predicted_center_error`、`Gmax`、`input_sat` 随 `T_p` 的变化趋势。

### E. 数据划分必须独立

最低要求：

1. tuning: `0-9`
2. validation: `10-39`
3. final: `40-99`

论文主表不能直接用 tuning 数据。

## 3. 当前执行顺序

为了最快形成可写论文的第一阶段闭环，执行顺序固定为：

1. 写清单
2. 跑 `validation split`
3. 汇总结论
4. 再决定是否进入 `final split`

## 4. 当前阶段是否达成闭环的判断标准

只要满足以下条件，就可以认为第一阶段已经达到“可写论文”的最小闭环：

1. `A` 组能证明基础模块有效；
2. `B` 组能说明围捕与角度覆盖的作用边界；
3. `C` 组能解释 `Omega` 的成败，而不是混在综合场景里看不懂；
4. `D` 组能给出 `T_p` 的趋势证据；
5. 所有结论使用 `validation split` 而非 tuning split。
