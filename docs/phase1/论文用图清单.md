# 论文用图清单

## 1. 目标

本清单用于约束论文主图数量，避免大量轨迹图堆叠，同时保证每一张图都服务于主叙事。

## 2. 正文主图

### 图 1：方法结构图

用途：说明 `F_nav / F_hyb / F_safe / F_topo / F_enc` 与 `rho` 的关系。

形式：

1. 结构框图；
2. 标出 `Omega -> eta(Omega)` 与 `Psi -> D(Psi)`；
3. 明确 `rho` 只调制 `F_topo`；
4. 在 `C` 组修正版本中标出 `rho_eff`。

### 图 2：基础正例轨迹图

推荐：

1. 场景：`A2 = s1_single_obstacle`
2. 方法：`M3`
3. 内容：单智能体绕障正例

用途：说明基础导航与混合绕障机制成立。

### 图 3：开阔围捕正例轨迹图

推荐二选一或并排：

1. `B3 + M7`
2. `B3 + M9`

用途：

1. 展示主干框架在开阔移动目标围捕中可运行；
2. 若并排放 `M7/M9`，可同时说明角度覆盖增强效果；
3. 建议在最终时刻按极角把智能体连成闭环，以强化围捕几何质量对比。

### 图 4：C组关键对比轨迹图

推荐并排：

1. `C2 medium + M4`
2. `C2 medium + SP-SMGF` 当前正式候选

用途：

1. 这是论文里最关键的一张困难场景行为图；
2. 用于说明结构保持修正如何改变通过行为。

### 图 5：C组状态曲线图

推荐：

1. 场景：`C2 medium`
2. 方法：`M7 原始版` 与 `SP-SMGF` 候选版
3. 曲线：`Omega / rho / psi_tilde`

用途：

1. 将轨迹变化与状态调制联系起来；
2. 支撑“原始标量调制会过度削弱拓扑支撑”的讨论；
3. 建议在图中标出 `approach / high-pressure / recovery` 三个阶段。

### 图 6：D1 趋势图

推荐：

1. 场景：`D1 = s6_fast_target`
2. 方法：`M7`
3. 横轴：`T_p`
4. 纵轴：
   - `completion_time_mean`
   - `current_center_error_mean`
   - `gmax_mean`
   - `radius_error_final_mean`

用途：

1. 明确 `T_p` 会系统性改变行为；
2. 同时说明当前尚未形成成功区间。

### 图 7：E组边界失败图

推荐：

1. 场景：`E1 = e1_tracking_single_obstacle`
2. 方法：`M7`
3. 内容：失败轨迹图

用途：

1. 作为综合耦合边界的可视化证据；
2. 不必漂亮，但要能说明“不是简单靠降速度或结构增强就能解决”。

## 6. 原则

1. 不要为每个场景放太多轨迹图；
2. 主图只保留“正例 + 对比 + 边界”三类；
3. `C` 组轨迹图和状态曲线图优先级最高；
4. `D1` 更适合用趋势图，不适合放太多失败轨迹；
5. `E1` 只需要一张边界失败图即可。
