## 3. 关键结果总结

## 3.1 Group A：基础模块已经基本成立

### A1 单智能体无障碍目标到达

结果：

1. `M1 success_rate = 1.0`
2. `M2 success_rate = 1.0`

结论：

1. 基础导航和输入有界映射没有问题；
2. 当前项目的底层运动生成机制是可运行的。

### A2 单智能体单障碍绕行

结果：

1. `M1 success_rate = 1.0`
2. `M2 success_rate ≈ 0.967`
3. `M3 success_rate = 1.0`
4. `M3 min_obs_distance` 略高于 `M1/M2`

结论：

1. `Curl` 项确实改变了绕障行为；
2. 当前 S1 场景还不足以把传统 APF 的局部极小完全放大出来；
3. 但至少能证明混合绕障项不是无效的。

### A3 多智能体安全对照

结果：

1. `M10 min_agent_distance ≈ 0.00067`
2. `M7 min_agent_distance ≈ 0.468`
3. 二者 `success_rate = 0`

结论：

1. `F_safe` 是必要的；
2. 没有安全项时，群体几乎发生完全重合；
3. 但当前安全项还不足以单独解决复杂交汇场景的内部碰撞。

## 3.2 Group B：围捕与角度覆盖已经有局部正证据，但还未完整打通

### B1 静态目标均匀初始围捕

结果：

1. `M4/M7 success_rate = 0`
2. 但 `collision_rate = 0`
3. `inside_final = 1.0`
4. `gmax_success_rate = 1.0`
5. `radius_success_rate = 0.0`

结论：

1. 当前失败主要不是碰撞问题；
2. 而是围捕半径约束没有满足成功阈值；
3. 这说明 `F_enc` 的半径收敛仍需继续调校。

### B2 同侧初始展开

结果：

1. `M4/M5/M6/M7 success_rate = 0`
2. `M9` 把 `gmax_mean` 从约 `274-275 deg` 降到约 `60 deg`
3. 但 `M9` 仍然 `collision_rate = 1.0`

结论：

1. 原始 `M7` 对角度覆盖改善有限；
2. 角度正则项 `M9` 可以显著改善 `Gmax`；
3. 但角度覆盖改善并不自动等于群体安全成功。

### B3 移动目标无障碍围捕

结果：

1. `M4 success_rate ≈ 0.967`
2. `M7 success_rate ≈ 0.967`
3. `M9 success_rate = 1.0`
4. `M9 gmax_mean ≈ 86 deg`，远小于 `M4/M7` 的约 `272 deg`

结论：

1. 这是当前最强的围捕正结果之一；
2. 在开阔移动目标场景中，主干框架已经具备运行能力；
3. 如果强调角度覆盖质量，增强版 `M9` 明显更好。

## 3.3 Group C：环境压力方向有意义，但当前主干还不能证明 `Omega` 的优势成立

### C1 宽通道

结果：

1. `M4 success_rate = 0.2`
2. `M5/M6/M7 success_rate = 0`
3. 失败主要由 `agent_collision_rate` 主导

### C2 中等通道

结果：

1. `M4 success_rate ≈ 0.567`
2. `M5/M6/M7 success_rate = 0`
3. 失败仍主要由 `agent_collision_rate = 1.0` 主导

### C3 窄通道

结果：

1. `M4 success_rate ≈ 0.333`
2. `M5/M6/M7 success_rate = 0`

结论：

1. 当前不能写成 `M7` 在通道场景中优于 `M4`；
2. 当前 `Omega` 调制的主要瓶颈不是障碍规避本身，而是通道约束下的群体内部安全与重构；
3. 因此当前关于 `Omega` 的论文表述必须保守，最多写成：

> 环境压力调制的方向具有合理性，但现有标量调制形式在通道约束下仍受群体内部挤压问题限制。

## 3.4 Group D：预测时间扫描已经给出趋势，但还没有形成成功区间

### D1 无障碍高速目标

结果：

1. 所有方法、所有 `T_p` 下 `success_rate = 0`
2. 但随着 `T_p` 增大：
   - `completion_time_mean` 明显下降
   - `current_center_error_mean` 下降
3. `M9` 的 `gmax_mean` 明显更小，但 `radius_error_final_mean` 更大

结论：

1. `T_p` 的改变确实系统性影响行为；
2. 但当前还没有出现从失败到成功的区间；
3. 当前瓶颈仍然是 `agent_collision_rate = 1.0`。

### D2 单障碍高速目标

结果：

1. 所有方法、所有 `T_p` 下 `success_rate = 0`
2. `M4` 的 `obs_collision_rate` 会随 `T_p` 增大而升高；
3. `M7` 的 `obs_collision_rate` 显著低于 `M4`，但仍全部失败；
4. `M9` 的 `gmax_mean` 持续下降，但 `obs_collision_rate` 反而更高。

结论：

1. 预测项与障碍项确实发生耦合；
2. 但当前还只能说“趋势存在”，不能说“最优预测时间区间已被验证”。

## 3.5 Group E：综合挑战场景当前仍全部失败

结果：

1. `E1/E2/dense easy/dense medium/dense hard` 中所有方法 `success_rate = 0`
2. 大多数配置 `obs_collision_rate = 1.0` 且 `agent_collision_rate = 1.0`
3. `M9` 明显改善了 `gmax_mean`，但没有带来成功率提升

结论：

1. 当前综合场景仍不能作为主干论文的正结果核心证据；
2. 它更适合作为后续阶段的挑战组与失败边界说明；
3. 这也再次说明：
   当前主干论文最好聚焦 `A/B/C/D` 的机制验证，而不是强行依赖 `E` 组。

## 3.6 Group F：安全力带来代价，但仍然必要

结果：

1. `A3` 中去掉安全项后，最小间距几乎退化到重合；
2. `B3` 中 `M7` 与 `M10` 差异很小，说明开阔场景下安全力代价不明显；
3. `S4-easy` 中 `M10` 会把群体压得更扁；
4. `D1/D2` 中去掉安全项并没有根本改善失败问题。

结论：

1. 安全力会带来一定任务性能代价；
2. 但它对维持最小群体间距仍然必要；
3. 当前问题不在于“删掉安全力”，而在于“如何减小安全力的副作用”。

## 4. 当前哪些主张已经可以写进论文

当前可以较稳妥写进论文的主张包括：

1. SMGF 主干框架在开阔和低难度场景下具备可运行性；
2. `F_safe` 对维持群体最小间距是必要的；
3. `F_enc` 能提供围捕半径收敛趋势，但仅靠半径项不足以保证角度覆盖；
4. 显式角度正则可以显著改善 `Gmax`；
5. 预测时间 `T_p` 的改变会系统性改变追踪行为；
6. 环境压力相关问题的核心瓶颈当前在于群体内部安全与拓扑软化方式冲突。

## 5. 当前仍不能写得太满的主张

以下内容当前不能写成已被完整验证：

1. `Omega` 明显提升窄通道通过率；
2. Full SMGF 在复杂障碍环境中整体优于固定拓扑；
3. 预测导航已经形成最优 `T_p` 区间；
4. 主干方法已经在综合挑战场景中稳定成功。

## 6. 当前阶段总判断

从完整 validation 结果看，最合理的结论是：

> 第一阶段主干论文现在已经具备“可写”的实验骨架，但其强证据主要集中在基础模块、开阔围捕和机制分解层面；对于窄通道压力调制、高速预测导航和综合障碍场景，目前更适合写成“趋势与边界”而不是“稳定优势”。

## 7. 下一步建议

为了让第一阶段主干论文更稳，建议后续优先级如下：

1. 优先补强 `C` 组，使 `M7` 至少在 `easy/medium` 通道中不劣于 `M4`；
2. 优先补强 `D1`，让无障碍高速目标场景先从全失败变成出现成功区间；
3. 把 `B3 + Group F` 作为当前主干论文里最稳定的正结果支撑；
4. 将 `E` 组更多作为局限性与后续研究方向展示。

## 8. 一句话总结

> 当前完整 validation 实验已经表明，SMGF-Core 的主干思想是成立且有研究价值的，但其最强证据目前来自基础模块、开阔围捕与机制分解，而不是复杂障碍综合成功率；因此第一阶段论文已经可以成立，但必须控制结论力度，把复杂障碍与通道场景的结果写成待补强的核心短板。
