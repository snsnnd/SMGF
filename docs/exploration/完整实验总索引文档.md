# 完整实验总索引文档

## 1. 文档目的

本文是整个项目当前实验体系的总索引，用于回答下面 4 个问题：

1. 整个项目到底做过哪些实验；
2. 各实验组代号分别在验证什么问题；
3. 各方法代号分别对应什么控制结构；
4. 应该先读哪些文档、看哪些输出目录，才能快速找到需要的实验结果。

本文不是单一实验报告，而是：

> 仓库级实验目录、方法目录、输出目录和阅读路径总表。

## 2. 全项目实验结构总览

当前项目实验体系可以分成 4 层。

### 2.1 第一层：Phase-1 主干实验

对应：

1. `A_basic_modules`
2. `B_encirclement_geometry`
3. `C_pressure_passage`
4. `D_prediction_navigation`
5. `E_integrated_challenges`
6. `F_safe_tradeoff`
7. `G_external_baselines`

用途：

1. 验证主干方法是否成立；
2. 分离基础模块、围捕结构、通道、预测导航、综合场景和安全项边界；
3. 提供正式 `phase1` 闭环数据。

### 2.2 第二层：Geo / Energy / Tensor / Polar 分支探索

对应：

1. `H` 到 `O` 组

用途：

1. 比较方向重组、能量统一、矩阵调制、张量理解、极性偏好这些方向是否有真实收益；
2. 判断当前 SMGF-Core 的主弱点到底在哪里。

### 2.3 第三层：连续模式、Xi、自定位、全局阶段分层

对应：

1. `P` 到 `U` 组

用途：

1. 验证连续模式层是否有用；
2. 验证 Xi 是否能提升执行层稳定性；
3. 验证全局阶段感知与局部 Xi 拆层后是否把问题压缩到底层执行器。

### 2.4 第四层：纯软规则 / 极性主轴 / 队列通过实验线

对应：

1. `V` 到 `AH` 组
2. `M31` 到 `M46` 方法链
3. `M44` 更难场景验证组

用途：

1. 单独研究纯软底层是否可以不依赖 QP/CBF 也实现稳定通道通过；
2. 研究 `Xi`、极性主轴、队列占位、leader pull、能量门控这些因素的作用边界；
3. 判断当前框架是否已经成立，剩下主要是能量工作区间问题还是结构表达本身问题。

## 4. Phase-1 主干实验组总表

这一层的实验组定义在：

`src/smgf/experiments.py`

### 4.1 `A_basic_modules`

目的：验证基础控制模块是否可运行。

场景：

1. `a1_single_goal_reach`
2. `s1_single_obstacle`
3. `a3_multi_agent_safety_crossing`

主要回答：

1. 基础导航和输入有界映射是否成立；
2. 单体绕障是否正常；
3. `F_safe` 是否确实能改善群体最小间距。

### 4.2 `B_encirclement_geometry`

目的：验证围捕构型与角度展开。

场景：

1. `b1_static_uniform_encirclement`
2. `s2_same_side_expansion`
3. `b3_moving_target_open_encirclement`

主要回答：

1. `F_enc` 是否能实现半径约束；
2. `Psi` 是否能帮助角度展开；
3. 预测导航在无障碍围捕中是否有效。

### 4.3 `C_pressure_passage`

目的：验证环境压力调制和通道通过。

场景：

1. `s4_narrow_passage_easy`
2. `s4_narrow_passage_medium`
3. `s4_narrow_passage_hard`

主要回答：

1. 压力调制方向是否合理；
2. 群体在宽/中/窄通道中的失效模式是什么；
3. 主问题是障碍识别、内部挤压还是队列组织不足。

### 4.4 `D_prediction_navigation`

目的：验证预测导航。

场景：

1. `s6_fast_target`
2. `d2_fast_target_single_obstacle`

主要回答：

1. 预测时间是否存在有效区间；
2. 快目标追踪是否可以通过预测稳定闭环。

### 4.5 `E_integrated_challenges`

目的：验证综合挑战场景。

场景：

1. `e1_tracking_single_obstacle`
2. `e2_tracking_sparse_obstacles`
3. `s5_dense_tracking_easy`
4. `s5_dense_tracking_medium`
5. `s5_dense_tracking_hard`

主要回答：

1. 多模块耦合后是否还能稳定运行；
2. 在带障碍移动目标追踪中，主失败模式是障碍、内部碰撞还是结构组织问题。

### 4.6 `F_safe_tradeoff`

目的：看安全项的边界和代价。

主要回答：

1. `F_safe` 是否必要；
2. 它是否只提供底线防撞，而不是严格安全保证。

### 4.7 `G_external_baselines`

目的：和外部风格基线比较。

方法：

1. `M3` APF-Curl
2. `M11` consensus ring
3. `M12` leader-follower
4. 主线 `M7/M9`

主要回答：

1. 当前主干方法相对经典连续控制基线的地位如何。

## 7. 纯软规则 / Xi 极性主轴实验线总表

这条实验线的详细方法说明，见：

`docs/exploration/xi_polarity_method_and_experiment_index.md`

这里给出在整个项目总索引中的定位。

### 7.1 研究问题

这条实验线单独研究：

> 在不依赖 QP/CBF 等硬执行器的前提下，只靠 `Xi`、极性主轴、连续软规则和能量门控，群体能否在通道中实现安全且高效的通过。

### 7.2 方法链

当前相关方法包括：

1. `M31` 磁性组织 + QP
2. `M32` Xi 调磁性 + QP
3. `M33` 纯磁性主导
4. `M34` 纯磁性 + 时距 / 优先权 / 迟滞释放
5. `M35` 纯磁性 + 基础推进能量 + curl
6. `M36` 更激进的软推进与旋度
7. `M37` 前车占位 / 后车掉推进
8. `M38` 后排顶前排的反证分支
9. `M39` Xi 极性主轴
10. `M40` Xi 极性主轴高能量
11. `M41` Xi 极性主轴 + occupancy
12. `M42` Xi 极性主轴 + leader pull
13. `M43` Xi 极性主轴 + occupancy + 高能量
14. `M46` Xi 极性主轴 + occupancy + 自适应能量

### 7.3 实验组链

1. `V`：先验证磁性组织是否有正信号
2. `W`：验证 Xi 是否能调磁性方向和大小
3. `X/Y/Z/AA`：验证纯软规则的边界
4. `AB/AC`：比较 occupancy 和 rear push
5. `AD/AE/AF/AG`：引入极性主轴，再比较能量、occupancy、leader pull
6. `AH`：专门测 `medium/hard` 上的能量工作区间
7. `M44`：验证 `M43` 是否只在特定场景有效
8. `AI`：验证 `easy` 版本调高能量是否更有效

### 7.4 当前阶段最重要的结论

这条实验线目前已经回答了几个关键问题：

1. `Xi` 进入下层是成立的；
2. 极性主轴是成立的；
3. `queue occupancy` 比“后排顶前排”更合理；
4. `leader pull` 更像启动机制；
5. `queue occupancy + 合适能量` 更像稳定主结构；
6. 当前最敏感的是推进能量工作区间；
7. `M43` 不是只在某个 toy scene 下有效。

## 10. 当前项目实验体系的一句话总结

整个项目的实验体系可以概括为：

> 先用 `Phase-1` 主干实验验证 SMGF-Core 是否成立，再用 `Geo / Energy / Tensor / Xi / 全局阶段 / ORCA / CBF / MPC / 纯软规则` 这些分支实验，一步一步定位当前系统在复杂约束环境中的真实瓶颈，并探索从“能运行”到“会组织”再到“会安全通过”的演化路径。
