# M43-M62 方法分析与 M43/M62 交叉验证（2026-06-16）

## 1. 目的

本文用于补齐当前仓库里 `M43-M62` 这一条 corridor/energy/release 分支的最新状态，重点回答 3 个问题：

1. `M43-M62` 各方法到底在加什么；
2. `M43` 和 `M62` 的表现是否具有跨场景、跨类型的非偶然性；
3. 现有旧文档里哪些判断已经需要修正。

对应代码主入口：

1. `src/smgf/core.py`
2. `src/smgf/experiments.py`
3. `src/smgf/understanding_analysis.py`

本次新增验证输出：

1. `outputs/bc_m43_m62_cross_type_validation_v1/`
2. `outputs/bd_m43_m62_dense_tracking_hard_v1/`

## 2. M43-M62 方法链摘要

按机制演化看，这一段不是 20 个互相独立的方法，而是一条连续分支：

1. `M43`：`Xi polarity axis + queue occupancy + high-energy drive`
2. `M46`：把固定 high-energy 改成自适应能量驱动
3. `M47`：单一 structured energy tank
4. `M48-M51`：双阶段 `approach -> transport` tank 与不同激活函数
5. `M52-M56`：双阶段能量链的分层消融
6. `M57`：入口能量沿队列传播
7. `M58`：leader-driven entry bonus
8. `M59`：global quota + Xi redistribution + explicit transport release
9. `M60`：统一状态 `r,w,q,a,e` 驱动 entry push
10. `M61`：front-loaded transport release
11. `M62`：spring-chain reduced transport release

当前最重要的结构事实：

1. `M44/M45` 在方法库里不存在，`M44` 只是一个实验组标签残留；
2. `M60` 在概念上更像 `M49` 的旁支，而不是 `M59` 的顺延；
3. `M61/M62` 已经实现，但此前没有接入标准实验分组，本次已补齐到 `AR/AS`。

## 3. 本次验证设计

### 3.1 方法选择

为了避免只做 `M43` 对 `M62` 的黑箱对比，本次同时纳入 4 个方法：

1. `M43`：当前强 through 原型
2. `M59`：global quota + release 映射
3. `M61`：front-loaded head release
4. `M62`：spring-chain reduced model

这样可以区分：

1. `M62` 的改善是不是只是因为“显式 release”
2. 还是确实来自“链式压缩支撑”

### 3.2 场景选择

本次故意混合两类场景：

1. corridor-pass：`c_geo_directional_passage_lite`、`s4_narrow_passage_medium`、`s4_narrow_passage_hard`
2. target-track：`e_geo_tracking_single_obstacle_lite`、`s5_tracking_stage2`、`s5_dense_tracking_hard`

这样做有两个目的：

1. 检查 `M62` 在真正相关的 through 场景里是否稳定提升；
2. 检查这些额外机制会不会在非 corridor 场景里产生伪提升。

### 3.3 随机性控制

本次统一使用验证种子段 `10-17`，每个场景 8 次重复，不使用单个展示 seed。

## 4. 关键结果

### 4.1 M43 仍然是当前最强 corridor through 原型

在本次验证种子段上：

| Scene | M43 success | M62 success | M43 `r_peak` | M62 `r_peak` |
| --- | ---: | ---: | ---: | ---: |
| `c_geo_directional_passage_lite` | 1.00 | 0.00 | 14.73 | 6.83 |
| `s4_narrow_passage_medium` | 1.00 | 0.00 | 14.56 | 7.20 |
| `s4_narrow_passage_hard` | 0.00 | 0.00 | 16.56 | 15.02 |

直接结论：

1. `M43` 在 `c_geo` 和 `s4_medium` 上稳定成功；
2. `M62` 虽然把 `r_peak` 明显推成正值，但在验证种子段上仍没有追平 `M43` 的 through 成功率；
3. `s4_hard` 上两者都没有成功，说明当前 spring-chain 版本还没有真正完成对 `M43` 的替代。

### 4.2 M62 对 M59/M61 的改善不是偶然，而是结构性改善

在 3 个 corridor 场景里，`M62` 相比 `M59/M61` 都稳定提高了以下量：

1. `magnetic_transport_release_proxy_mean`
2. `magnetic_effective_drive_mean`
3. `entry_flux_mean`
4. `spring_chain_storage_mean`
5. `spring_rear_support_mean`
6. `spring_transport_hold_mean`

以 `s4_narrow_passage_medium` 为例：

| Method | `r_peak` | `entry_flux` | `effective_drive` | `release_proxy` |
| --- | ---: | ---: | ---: | ---: |
| `M59` | -0.49 | 0.098 | 0.156 | 0.080 |
| `M61` | -0.71 | 0.093 | 0.149 | 0.082 |
| `M62` | 7.20 | 0.291 | 0.373 | 0.179 |

这说明：

1. `M61` 没有证明“把 release 往头部堆”就够了；
2. `M62` 的改进来自链式储能和后段支撑共同抬升 through 通量；
3. 因此 `M62` 的增益不是随机波动，而是和 spring-chain 观测量同步出现的结构性改善。

### 4.3 M62 还没有击败 M43，但它已经击败了 M59/M61

最准确的当前判断不是“`M62` 已经赢了”，而是：

1. `M62` 已经把 `M59/M61` 这条 release 线从负 `r_peak` 区间推到了显著正 `r_peak` 区间；
2. 但它仍然没有在验证种子段里复制 `M43` 的 through 成功率；
3. 因而 `M62` 目前更像“正确方向上的 reduced model”，还不是“可替代 `M43` 的最终版本”。

### 4.4 target-track 场景的“完全重合”恰好是负对照

在以下非 corridor 主任务场景中：

1. `e_geo_tracking_single_obstacle_lite`
2. `s5_tracking_stage2`
3. `s5_dense_tracking_hard`

`M43/M59/M61/M62` 的主要统计量几乎完全一致。

这不是坏事，反而说明了两点：

1. 这些新增机制确实主要被限制在 corridor 分支内；
2. 本次 `M62` 在 corridor 场景里的提升，不是“换个方法名后所有场景都同步变好”的伪提升。

因此这些 target-track 场景在本次实验里起到的是高难度负对照作用。

## 5. 对 M43 与 M62 的当前结论

### 5.1 M43

`M43` 当前仍然是：

1. 真实 through 能力最强的经验原型；
2. corridor success rate 的最强基线；
3. 统一 reduced model 需要逼近而不是回避的对象。

### 5.2 M62

`M62` 当前最可信的定位是：

1. 它没有偶然性，因为在多个 corridor 场景、8 个验证 seed 上都稳定抬升了 `release_proxy / effective_drive / entry_flux / r_peak`；
2. 它也没有被夸大，因为这些改善还不足以把 `success_rate` 提升到 `M43` 的水平；
3. 它最有价值的地方，是把“头部释放不够，必须有后段压缩支撑”这个判断写成了可观测、可重复的数据事实。

## 7. 当前最稳的下一步

如果继续沿 `M62` 方向推进，最值得做的不是再加一个新的 head bonus，而是：

1. 直接对比 `M43` 与 `M62` 的 `queue_scale / drive_intent / effective_drive / entry_flux` 时间历程；
2. 检查 `M62` 为什么在 `r_peak` 已为正时，仍然没有转化成 corridor dwell success；
3. 把差距收缩到 `through 成功保持` 而不只是 `进入势垒跨越`。

一句话总结：

> `M43` 仍是当前最强 through 原型；`M62` 已证明“主动弹簧链”方向不是偶然，但它目前只能稳定优于 `M59/M61`，还不能稳定替代 `M43`。
